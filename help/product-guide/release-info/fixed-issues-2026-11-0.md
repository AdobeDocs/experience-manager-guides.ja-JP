# 2026.11.0 リリースで修正された問題

この記事では、Adobe Experience Manager Guides as a Cloud Serviceの2026.11.0 リリースの様々な領域で修正されたバグについて説明します。

新機能と機能強化について詳しくは、[2026.11.0 リリース &#x200B;](./whats-new-2026-11-0.md)の新機能を参照してください。

2026.11.0 リリース [&#128279;](./upgrade-instructions-2026-11-0.md)の アップグレード手順について説明します。

## エディター2.0

- エディターのパンくずリストを使用してテーブルの行を選択し、コンテキストメニューから&#x200B;**削除** オプションを選択すると、行全体を削除する代わりに、セルの内容のみが削除されます。 （GUIDES-56759）
- Microsoft Wordから表を貼り付けると、見出し行のセルが作成されますが、その内容は失われます。 （GUIDES-49847）
- エディター2.0に移動する前に作成されたファイルの変更履歴は、**変更履歴** パネルには表示されません。 （GUIDES-44777）
- Microsoft Wordまたは同様のテキストエディターから`codeblock`要素にコードをペーストする際に、Ctrl+Vを使用すると、改行と行送りスペースが失われ、コードが1行に統合されます。 （GUIDES-33247）

## オーサリング

- 統合シェルが有効になっている場合は、Adobe Experience Manager Guides ヘッダーがエディターとマップコンソールにも表示されます。 （GUIDES-56812）
- Assets UIでは、**ソースを表示**、**トピックを編集**、**UUID リンクを共有**&#x200B;などのDITA固有のアクションが、DITA以外のアセットに対して表示されます。 さらに、**UUID リンクを共有**&#x200B;すると、UUIDのないアセットに対して無効なリンクが生成されます。 （GUIDES-47043）
- 件名スキーム パネルでは、表示タイトルは`navtitle`属性からのみ選択されます。 `navtitle`要素は、両方が存在する場合でも無視されます。 （GUIDES-37722）
- リポジトリパネルの&#x200B;**タイトルビュー**&#x200B;では、最初は長い名前のファイルに対して省略記号は表示されません。 このようなファイルを右クリックすると、省略記号とコンテキストメニューがファイルの右側に表示され、一部が画面に表示されないことがあります。 （GUIDES-37118）
- 条件パネルでは、条件はラベルではなく値に基づいてアルファベット順に並べ替えられます。 （GUIDES-14593）
- レイアウト.cssなどのスタイルシートを開いたときに、出力テンプレートで&#x200B;**新しいスタイル** （+）ボタンがスタイルパネルに表示されません。 （GUIDES-49448）

## アセット管理

- 「**既存のファイルを上書き**」オプションを使用して変更されたファイルをアップロードすると、既存のファイルにGuides UUIDがなく、**後処理の無視されたパス**&#x200B;の下にあるフォルダーに保存されている場合、アップロードが完了するように見えます。 ただし、既存のファイルは上書きされず、新しいバージョンは作成されません。 （GUIDES-55866）
- ブックマップでは、`booktitle`要素に`booklibrary`や`mainbooktitle`などの複数のサブ要素が含まれている場合、`dc:title` メタデータの値の間に余分な空白が追加されます。 （GUIDES-28877）

## 公開

- マップコンソールで、あるマップに対して出力を生成すると、別のマップを開いたときに「**生成**」ボタンが無効になります。 ブラウザーを更新すると、ボタンが再度有効になります。 （GUIDES-54591）
- コンポーネントマッピングを使用して特定のマップをAEM サイトに公開すると、目次の作成中にエラーが発生して失敗します。 （GUIDES-53807）
- コンポーネントマッピングを使用してAEM サイトにマップを公開すると、マップに`navtitle`属性を持つ`topicref` エレメントが含まれ、`href`属性が含まれていない場合に失敗します。 その後の試行も、生成されたサイトノードが削除されるまで、要素が削除された後でも失敗します。 （GUIDES-53707）
- コンポーネントマッピングを使用したAEM サイト出力では、レベル 2 ～ 6のマークダウン見出しはレベル 1見出しとしてレンダリングされます。 （GUIDES-51134）
- コンポーネントマッピングを使用したAEM サイト出力では、作成者、キーワード、リソース IDなどのプロログメタデータが、公開された出力のページ本文に表示されます。 （GUIDES-44087）
- トピックがServiceNowに公開されると、そのトピックの簡単な説明とprologが記事本文に含まれます。 （GUIDES-47868）
- ServiceNowで既に公開されているトピックが再度公開されると、既存の記事が上書きされるのではなく、ドラフト状態で新しい記事が作成されます。 （GUIDES-37872）
- 条件プリセットでSalesforceへの公開中にトピック参照を除外すると、残りのトピックが正常に公開されていても、出力の生成に失敗が報告されます。 （GUIDES-37807）
- 大きなマップをSalesforceに公開すると、ゲートウェイタイムアウトエラーが発生して失敗します。 （GUIDES-33722）
- リクエストに25を超える操作が含まれている場合、Salesforceへのマップの公開に失敗し、制限超過エラーが発生します。 （GUIDES-33721）
- マップダッシュボード（旧）で、**既存の条件プリセット内のすべての**&#x200B;を追加しても、プリセットの作成後に追加または変更された条件値は取得されません。 （GUIDES-45940）
- 警告を含む&#x200B;**出力履歴** ページ内のログには、緑色のアイコンが表示されます。これは、警告が存在することを示すものではありません。 （GUIDES-27000）
- マップコンテンツ内で用語集エントリを参照する用語がない場合、用語集は出力に含まれません。 （GUIDES-52964）
- 付録で参照されているサブマップのトピックは、付録コンテンツではなくチャプターとしてレンダリングされます。 （GUIDES-52775）
- 出力言語が中国語（簡体字）に設定されている場合、一部の簡体字は日本語フォントでレンダリングされます。 （GUIDES-48094）
- 索引項目は、`keyword`、`ph`、`sup`などの子要素のテキストを失います。 その結果、一部のインデックスラベルが不完全または空になります。 （GUIDES-40902）
- インライン `option`要素の周囲のスペースは保持されないため、隣接するテキストが結合されて表示されます。 （GUIDES-40900）

## 翻訳

- 翻訳ページで、**タイトル**&#x200B;で検索および並べ替えを行う場合は、列に表示されるタイトルではなく、ローカライズされたメタデータ値を使用します。 （GUIDES-45396）

## レビュー

- **レビュー担当者** ページでは、レビュータスクの作成中または編集中に、**選択範囲をクリア**、**レビュー担当者の追加**、**レビュー担当者の削除**&#x200B;および&#x200B;**レビュー担当者の再割り当て** ボタンが、行が選択されていない場合でも、デフォルトで有効になっています。 （GUIDES-35125）
- AEMのインボックスには、タスクの割り当て、フィードバックの受信、メンション、期限または期限切れのリマインダーなど、レビュータスクに関連する通知が、プロジェクト名なしで表示されます。 （GUIDES-10912）
- レビュータスクのトピックを並べて表示すると、2つのビューに取り消し線でマークされたコンテンツが異なる形式で表示されます。 （GUIDES-56079）

## 学習コンテンツ

- 通常300 MBから600 MBの大規模なコースのSCORM出力の生成には30分以上かかり、ログにエラーの詳細が含まれずに失敗します。 （GUIDES-56101）
- SCORM出力の完了条件をExperience Manager Guidesで設定することはできません。 （GUIDES-55520）
- AVIF形式の画像はエディターに表示されますが、公開された出力には表示されません。 （GUIDES-55515）
- `href`属性は、公開出力のアンカータグから削除されるので、リンクはクリックできません。 （GUIDES-55514）

## プラットフォーム

- ユーザーがフォルダープロファイルで管理者ユーザーとして割り当てられているが、管理者グループのメンバーではない場合、他の管理者ユーザーを正常に追加することはできません。 成功メッセージが表示されますが、新しく追加されたユーザーはページを更新すると消えます。 （GUIDES-50144）

## 既知の問題

Adobeでは、2026.11.0 リリースの次の既知の問題を特定しました。

## オーサリング

- 依存トピックまたはサブマップを含むテンプレートからマップを作成する場合、特にサーバーの負荷が高い場合、マップの作成がエラーで断続的に失敗することがあります。 （GUIDES-58715）

### エディター2.0

- **ナビゲーションタイトル属性** オプションを更新しても、DITA マップ内の既存の`topicref`要素に`@navtitle`属性が追加されません。 （GUIDES-54348）

**変更を追跡**

**変更履歴**&#x200B;がオンになっている場合：

- 同じユーザーによるネストされた削除は、削除されたコンテンツを含む要素の名前が変更されたり、形式が変更されたりすると、必ずしも1つのエントリに統合されるわけではありません。 （GUIDES-58429）
- ネストされた削除が別のユーザーによって行われた場合、**変更を追跡** パネルに親エレメントのコンテンツが不完全な場合があります。 （GUIDES-58428）
- 別のユーザーが作成した挿入内のコンテンツを削除しても、赤い間隔マーカーは左側には表示されません。 （GUIDES-58418）

### 公開

- ネイティブPDF出力では、上付き文字と下付き文字の書式はインデックスエントリに保持されません。 （GUIDES-58349）
- 同じグローバルプリセットを使用して異なるマップの出力を生成する場合、前のマップのトピック選択が新しいマップの出力に影響を与える可能性があります。 （GUIDES-58346）
- ブックマップを公開すると、特定のシナリオで`<chapter>`が直接`href` ターゲットを同時に定義し、その章にネストされた`<topicref>`子要素が含まれている場合、空白ページになることがあります。 （GUIDES-58266）
- 未保存の変更を含むプリセットから&#x200B;**出力履歴** タブに移動すると、**保存**&#x200B;および&#x200B;**出力を生成** ボタンが表示されたままになります。 （GUIDES-57989）
- 公開後ワークフローがプリセット用に設定されている場合、**出力履歴**&#x200B;に表示される公開期間には、ワークフローで実行された時間は含まれません。 （GUIDES-57856）
- **出力履歴** ページからネイティブ PDF出力の生成をキャンセルすることはできません。 （GUIDES-57821）

### レビュー

- 2026.08.0または2026.09.0 リリースで作成されたレビュータスクを開くと、レビュー済みコンテンツに&#x200B;*任意のレビュー注釈*&#x200B;が非改行スペース（`&nbsp;`）と共に含まれている場合、アプリケーションエラーが発生することがあります。 （GUIDES-56583） <br>**回避策：**&#x200B;これらのリリースで作成されたすべてのレビュータスクを完了または閉じます。
