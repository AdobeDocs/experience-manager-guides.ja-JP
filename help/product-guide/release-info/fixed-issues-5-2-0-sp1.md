# 5.2.0 サービスパック 1 リリース（2026年9月）で修正された問題

この記事では、Adobe Experience Manager Guidesの5.2.0 Service Pack 1 リリースの様々な領域で修正されたバグについて説明します。

5.2.0 サービスパック 1 リリース [&#128279;](upgrade-instructions-5-2-0-sp1.md)の アップグレード手順について説明します。

## オーサリング

- 低解像度の画面では、ツールバーからキーワードを挿入する際にキーワードの挿入ダイアログが表示されず、**More** オプションを使用すると期待どおりに開きます。 （GUIDES-48304）
- **Web リンク** オプションを使用して相互参照を挿入すると、`scope=external` リンクを想定どおりに挿入する代わりに、`scope=local` リンクが追加され、`href`値が変更されます。 （GUIDES-48457）
- 参照マップを保存すると、1人の作成者が参照マップを移動する際に、別の作成者が保存されていないマップで参照を同時に追加している場合に、正しいマップに解決されるのではなく、壊れた参照が発生します。 （GUIDES-47467）
- ディクショナリに追加された英数字の用語は、無視される代わりに、AEM スペルチェッカーによってフラグが立てられます。 （GUIDES-48587）
- `in`、`mm`、`px`などの単位ベースのサイズを使用して、画像プロパティダイアログの&#x200B;**幅** フィールドと&#x200B;**高さ** フィールドの間でフォーカスを切り替えると、値は安定したままではなく、徐々に増加し続けます。 （GUIDES-45929）

## エディター2.0

- テーブル セル `<entry>`内のインライン タグの直前に入力された空白が削除されます。 （GUIDES-49144）
- `tgroup`の位置に要素を挿入すると、**#textがここでは許可されない**&#x200B;警告が表示され、その位置に通常のテーブルを挿入できません。 （GUIDES-47446）
- Excel スプレッドシートから表をコピーして新しいエディターに貼り付けると、コピーしたすべてのセルの内容が、対応するセルに配布されるのではなく、1つの表セルに配置されます。 （GUIDES-47435）
- カスタム **PDFとして書き出し** ボタンは、`editor_toolbar.json`を通じてレンダリングされ、プレビューモードでクリック可能なままですが、クリックしてもアクションは実行されません。 （GUIDES-47402）
- テーブルを含む特定のトピックを開くと、トピックに変更が加えられていない場合でも、2つの新しい列を含む予期しない`<foreign>` タグが追加されます。 （GUIDES-46748）
- MathML数式を`conref`として挿入すると、正しくレンダリングされません。 （GUIDES-46601）
- MathMLおよびSVGの要素は、属性のセット全体をレンダリングしないため、カスタム CSS クラスおよびこれらの要素に適用された条件付き属性が壊れます。 （GUIDES-46371）
- **スケール**&#x200B;属性は、作成者ビューの画像には適用されません。 （GUIDES-45996）
- テーブルに`scale`属性を適用しても、作成者モードとプレビューモードで設定されたサイズでテーブルがレンダリングされません。 （GUIDES-45984）
- ペイントやスニッピングツールなどの外部ソースからコピーした画像をペーストしても、その画像はトピックに挿入されません。 （GUIDES-45983）
- `<keydef>`または`<topicref>`内の`<topicmeta>`内の`<keywords>`をコピーして貼り付けると、キーワードが不要な外部タグ内に挿入されます。 （GUIDES-45800）
- 表のタグビューで、折りたたまれたエントリタグのすぐ下のセルにカーソルを置いたときに上向き矢印キーを押すと、折りたたまれたタグの上をスキップして、カーソルを文書の先頭に移動します。 （GUIDES-45408）
- テーブルのコンテキストツールバーから操作を実行すると、ツールバーが予期せず閉じられ、その後のテーブル操作が中断されます。 （GUIDES-45405）
- 読み取り専用モードまたは他のユーザーがファイルをチェックアウトすると、**MathML**&#x200B;を編集オプションが正しく表示されず、ファイルを編集不可にしていても、ユーザーがMathML コンテンツを更新できなくなります。 （GUIDES-45172）
- アウトライン表示またはパンくずリストから&#x200B;**挿入後**&#x200B;または&#x200B;**挿入前**&#x200B;を使用した後、新しく追加されたタグ内ではなく、任意の位置にカーソルが移動します。 （GUIDES-45147）
- タグビューを有効にしてドラッグ&amp;ドロップを実行する場合、部分的なXMLまたはDITA タグと共にコンテンツを選択すると、不要な孤立タグが残り、コンテンツまたはビューが正しく表示されません。 （GUIDES-28191）

## アセット管理

- バージョンのパージ・ユーティリティは、パージを完了して正確なレポートを生成する代わりに、特定のファイル・タイプ、メタデータが欠落しているアセット、大きなレポートなど、複数のシナリオで完了できません。 （GUIDES-43453）

## 公開

- 生成されたページ名の英語以外のファイル名はハイフンに置き換えられるため、従来のコンポーネントマッピングを使用してAEM Sites出力を公開する際に、関連するトピックまたはファイルを特定するのが困難になります。 （GUIDES-48387）
- DITA-OT パッケージのAEM Guidesにバンドルされている脆弱な`jackson-databind` JAR （バージョン 2.9.8）が特定されます。 （GUIDES-43081）

## レビュー

- コメント パネルで&#x200B;**横に** ビューを開くと、作業中のコピーがコメント付きバージョンと一緒に表示されますが、ペインは水平方向にスクロールせず、コメントをクリックしてもカーソルが対応するテキストに移動しません。 （GUIDES-44083）

## プラットフォーム

- トピックまたはマップ内のDAM コンテンツへの参照に`scope="external"`を使用すると、アセットの相対パスがGUIDで置き換えられます。 （GUIDES-35605）
- UUID移行前に作成されたコンテンツについて、**ファイル階層を保持**&#x200B;および&#x200B;**実際のファイル名を使用** オプションを選択してマップをダウンロードすると、元の相対ファイルパスを保持する代わりに、`topicref`、`xref`、および`conref`要素の`href`値が`scope="external"`でGUID ベースのファイル名に誤って変換されます。 その結果、外部参照が壊れます。 （GUIDES-46526）
- Assets UIを介してアセットをアップロードする場合、アップロードステータスは表示されません。 （GUIDES-7207）

## 既知の問題

- コードブロック内でレビュー操作を実行すると、最初の試行では&#x200B;**操作は許可されていません**&#x200B;という警告が表示されますが、操作は繰り返し実行すると成功します。 （GUIDES-56749）
- `code block`を含むコンテンツのレビュータスクを作成すると、読み込み後に取り消し線の書式設定が正しく適用されず、ハイライトされたコンテンツが並べて表示されない。 （GUIDES-56811）
- マップに複数のトピックが含まれている場合でも、レポートパネルの「**トピックリスト**」タブに結果が表示されない場合があります。 （GUIDES-56893） <br> **回避策：**&#x200B;影響を受けるコンテンツを再インデックス化して、親マップの関係を再構築します。 トピックは、期待どおりにトピックリストタブに表示されます。
- アウトライン表示で処理命令エレメントを選択すると、選択したエレメントではなく親タグ全体がハイライト表示されます。 （GUIDES-48318）
- 削除操作を実行する際に、画像マップ、構造化要素、インライン書式設定タグ、およびマージできないブロックで、カーソルの移動やナビゲーションに多少の不整合が発生する可能性があり、予期しないカーソルや削除動作が発生することがあります。 （GUIDES-46756）
- `foreign`および`equation` ブロック内で囲まれたMathML数式は、不要な間隔を設定することになり、数式の内部で入力すると、インデントを調整した後でも問題が発生します。 （GUIDES-46606）
- **タグを表示** オプションが有効で、**属性を表示** オプションがエディター設定で無効になっている場合、`reltable`内の`topicref`にカーソルを配置できません。 （GUIDES-46565）
- 読み取り専用コンテンツ（conref段落など）の直後の段落の先頭でバックスペースを押すと、編集可能な段落が予期せず削除または結合され、編集可能な段落が予期せず削除される可能性があります。 （GUIDES-45049）
- 「エレメントの名前を変更」オプションを使用してインラインタグの名前を変更した場合、ブレッドクラムはすぐに更新されず、カーソルをタグに移動するかビューモードを変更した後にのみ変更が反映されます。 （GUIDES-44993） <br>**回避策：** インラインタグの名前を変更してブラウザーを更新し、パンくずリストを更新します。
- 条件インジケーターをbodydivなどの要素に適用すると、インジケーターがフルタグビューの隣接するタグにオーバーフローし、誤った視覚的なレンダリングが発生します。 （GUIDES-44971）
