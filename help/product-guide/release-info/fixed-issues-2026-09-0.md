# 2026.09.0 リリースで修正された問題

この記事では、Adobe Experience Manager Guides as a Cloud Serviceの2026.09.0 リリースの様々な領域で修正されたバグについて説明します。

新機能と機能強化について詳しくは、[2026.09.0 リリース &#x200B;](./whats-new-2026-09-0.md)の新機能を参照してください。

2026.09.0 リリース [&#128279;](./upgrade-instructions-2026-09-0.md)の アップグレード手順について説明します。

## エディター2.0

- 作成者モードからテーブルをコピーして作成者モードにペーストすると、`colwidth`などの属性や`colspec`で定義されているその他の属性が削除され、列幅の設定が失われます。 （GUIDES-52916）
- テーブル セル `<entry>`内のインライン タグの直前に入力された空白が削除されます。 （GUIDES-49144）

## オーサリング

この節では、エディター1.0とエディター2.0の両方に共通するオーサリングで修正されたバグについて説明します。

- 低解像度の画面では、ツールバーからキーワードを挿入する際にキーワードの挿入ダイアログが表示されず、**More** オプションを使用すると期待どおりに開きます。 （GUIDES-48304）
- 空のルールファイルでSchematron検証が設定されている場合にトピックを保存すると、不正確で一般的なエラーメッセージが表示されます。 （GUIDES-48106）
- テキストノードコンテキストを使用するSchematron ルールは、検証をトリガーしません。 （GUIDES-14500）
- **Web リンク** オプションを使用して相互参照を挿入すると、`scope=external`を想定どおりに挿入するのではなく、`scope=local` リンクが追加され、`href`値が変更されます。 （GUIDES-48457）
- 参照マップを保存すると、1人の作成者が参照マップを移動する際に、別の作成者が保存されていないマップで参照を同時に追加している場合に、正しいマップに解決されるのではなく、壊れた参照が発生します。 （GUIDES-47467）

## アセット管理

- アセットステータス APIは、パスにコンマが含まれているアセットの正しいステータスを返しません。 （GUIDES-49065）
- Assets管理者検索レールのDITA エレメントフィルターは、入力された値を適用しないため、検索結果はフィルタリングされません。 （GUIDES-48450）
- バージョンのパージ・ユーティリティは、パージを完了して正確なレポートを生成する代わりに、特定のファイル・タイプ、メタデータが欠落しているアセット、大きなレポートなど、複数のシナリオで完了できません。 （GUIDES-43453）
- Assets UIの「移動」操作を使用して、GUID ベースのファイル名を持つアセットの名前を別のGUIDに変更すると、アセットの元の一意のGUIDが新しいGUIDに置き換えられます。 （GUIDES-43006）

## 公開

- 古いバージョンを対象としたベースラインでAEM Sites（複合コンポーネントマッピング付き）出力を生成すると、ページコンテンツには古いバージョンが正しく表示されますが、ページメタデータには現在のバージョンが表示されます。 （GUIDES-49325）
- 一括アクティベーションを使用してページをレプリケートする場合、レプリケーショントラッキングプロパティはルートページにのみ設定され、子ページには設定されないため、前回のレプリケーション以降に変更されたコンテンツを特定することが困難です。 （GUIDES-37871）
- ベースラインを作成/編集ダイアログの&#x200B;**ラベル** フィールドに初めてフォーカスが表示された場合、最初の文字を貼り付けたり入力したりしても、オートコンプリートの候補が正しくフィルタリングされず、フィルターされた結果ではなく、すべての候補がフィールドに表示されます（GUIDES-50143）。
- ブランチフィルタリングは、`keydef`として使用される不要なトピックに対して追加のページを生成します（DITA-OTによって`resource-only ="true"`とマークされます）。 （GUIDES-19701）
- マップコレクションは、まだ生成されていないプリセットに対して&#x200B;**公開** オプションを有効にします。 （GUIDES-50510）
- 新しく作成されたマップコレクションに公開レコードがない場合、「公開履歴」セクションにプレースホルダーテキストが表示されません。 （GUIDES-50366）
- ネイティブ PDF プリセットにICC カラープロファイルを適用すると、出力生成が失敗し、ダイレクトプロファイルパスを使用してもCMYK カラーが正しくレンダリングされません。 （GUIDES-47137）
- ネイティブPDF プリセットで設定された裁ち落とし設定は、生成された出力に反映されません。 （GUIDES-47034）
- テーブルの続きの&#x200B;**改行の前のテキスト** フィールドは、ローカライズされた文字列のみをレンダリングし、ページ番号のプレースホルダーは置き換えません。 （GUIDES-32872）
- ICC プロファイルブラウザーで、ICC ファイルのみを表示するのではなく、DITA ファイルが正しく表示されない。 （GUIDES-25017）
- ドラフトコメントは、ネイティブPDF出力でレンダリングされません。 （GUIDES-47044）
- `title`要素の中に配置されたドラフトコメントが、公開出力に予期せず表示されます。 （GUIDES-10686）
- マップダッシュボードで、別のプリセットトリガーを選択すると、ピアリンクを取得するための呼び出しが行われ、その結果、さらに処理が行われます。 （GUIDES-53703）

## 翻訳

- XLIFF プロジェクトを使用して翻訳を開始すると、空のプロジェクトが作成され、進行中の状態に移動することはありません。 （GUIDES-51759）
- アセットの移動操作を使用してコンテンツを言語フォルダーから別のフォルダーに移動すると、作成者は翻訳パネルでそのコンテンツを翻訳用に選択できなくなります。 （GUIDES-49386）
- 同じプロジェクトの別の翻訳リクエスト（新しいプロジェクトの作成または&#x200B;*既存の*&#x200B;への追加リクエスト）がまだ競合の結果を処理している間に、**既存の翻訳プロジェクトに追加** オプションを使用してアセットを翻訳用に送信します。 （GUIDES-49354）

## ベースライン

- プリセットの保存されたベースライン選択は、ベースラインを削除した後、または動的ベースラインの作成中に&#x200B;*ベースラインなし*&#x200B;と誤って表示されます。 （GUIDES-52690）

## レビュー

- レビューパネルを開いたり、プロジェクトフィルターを適用したりすると、タスクリストの読み込みに時間がかかります。 （GUIDES-48893）

## レポート

- 多数のトピックを含むマップの壊れたリンク レポートを生成すると、レポートインターフェイスが&#x200B;**壊れたリンクの詳細を取得** メッセージを無期限に取得する際に停止したままになり、ブラウザーが応答しなくなり、最終的にクラッシュする原因になります。 （GUIDES-37845）

## 学習コンテンツ

- HTMLまたはカスタムヘッダー付きの学習テンプレートを使用して新しい学習トピックを作成した場合、トピックタイトルはカスタムヘッダーに表示されません。 （GUIDES-52343）
- コースクイズの計算された正確性の割合は、期待値とわずかに異なります。 （GUIDES-52346）
- コースの場合、クイズを試みる際の点数は、予想される計算スコアと若干異なります。 （GUIDES-52345）

## 既知の問題

Adobeでは、2026.09.0 リリースの次の既知の問題を特定しました。

- 既にロックされているトピックのドキュメントの状態を変更すると、ドキュメント全体が更新されます。 （GUIDES-53905）
- ベースライン機能を使用してプレビューを使用する場合、大きなマップ（10,000以上のトピック）または多数の`keydefs`を持つマップ（100 `keydefs`と3,500のトピックなど）のプレビューリクエストのタイムアウトが発生します。 （GUIDES-54147）
- DB サーバーの場合、`href`を含まない`keydef`を含むマップがプレビューされ、「ベースラインを使用してプレビュー」オプションが有効になっている場合、`keydef`は解決されません。 （GUIDES-53878）
- 画像マップアセットで設定されたホットスポット領域は、プレビューモードではインタラクティブではないため、作成者は公開前にホットスポットリンクを検証できません。 （GUIDES-53398） <br>**回避策**：画像マップに変換する画像を挿入し、コンテキストメニューから「**画像マップを編集**」を選択して、ホットスポットリンクを設定します。
- マップを開いている間に、既存のベースラインを含むマップを別のフォルダーに移動すると、「**ベースラインを使用してプレビュー**」トグルはプレビューモードで選択されたままになりますが、ベースラインはドロップダウンリストに表示されなくなります。 （GUIDES-54284） <br>**回避策**: マップを閉じて再度開き、問題を解決できます。
- 新しく設定されたAEM Cloud Service環境（AEM as a Cloud Service SDK）で、マップまたはトピックファイルを作成しようとすると、*ファイルを作成できませんでした* エラーまたは&#x200B;*DTD ルールの取得エラー*&#x200B;が発生します。 （GUIDES-53904） <br>**回避策**: AEM Cloud Service環境を再起動できます。
- 2人の作成者が同じトピックを同時に作業する場合、一方の作成者が開いているトピックをロックしても、もう一方の作成者が変更した後でも、バージョン番号、ラベル、ドキュメントの状態、タグなどのメタデータプロパティが更新されず、古い値が引き続き表示されます。 （GUIDES-54810） <br>**回避策**: トピックを閉じて再度開き、メタデータを更新して最新の値を表示します。
