# 2026.08.0 リリースで修正された問題

この記事では、Adobe Experience Manager Guides as a Cloud Serviceの2026.08.0 リリースの様々な領域で修正されたバグについて説明します。

新機能と機能強化について詳しくは、[2026.08.0 リリース &#x200B;](whats-new-2026-08-0.md)の新機能を参照してください。

2026.08.0 リリース [&#128279;](upgrade-instructions-2026-08-0.md)の アップグレード手順について説明します。

## オーサリング

- マップダッシュボードのトピックレポートからアクセスすると、エディターでトピックが開かない。 （GUIDES-45277）


## エディター2.0

- MathML数式を`conref`として挿入すると、正しくレンダリングされません。 （GUIDES-46601）
- `<keydef>`または`<topicref>`内の`<topicmeta>`内の`<keywords>`をコピーして貼り付けると、キーワードが不要な外部タグ内に挿入されます。 （GUIDES-45800）
- マップエディターで壊れたリンクで`Ctrl+click`を使用すると、アプリケーションエラーがトリガーします。 （GUIDES-45544）
- Excel スプレッドシートから表をコピーして新しいエディターに貼り付けると、コピーしたすべてのセルの内容が、対応するセルに配布されるのではなく、1つの表セルに配置されます。 （GUIDES-47435）
- カスタム **PDFとして書き出し** ボタンは、`editor_toolbar.json`を通じてレンダリングされ、プレビューモードでクリック可能なままですが、クリックしてもアクションは実行されません。 （GUIDES-47402）
- MathMLおよびSVGの要素は、属性のセット全体をレンダリングしないため、カスタム CSS クラスおよびこれらの要素に適用された条件付き属性が壊れます。 （GUIDES-46371）
- テーブルを含む特定のトピックを開くと、トピックに変更が加えられていない場合でも、2つの新しい列を含む予期しない`<foreign>` タグが追加されます。 （GUIDES-46748）
- **スケール**&#x200B;属性は、作成者ビューの画像には適用されません。 （GUIDES-45996）
- `keyref`を含む要素をドラッグ&amp;ドロップすると、`keyref`値が絶対パスに変換されます。 （GUIDES-45701）
- `tgroup`の位置に要素を挿入すると、**#textがここでは許可されない**&#x200B;警告が表示され、その位置に通常のテーブルを挿入できません。 （GUIDES-47446）
- ディクショナリに追加された英数字の用語は、無視される代わりに、AEM スペルチェッカーによってフラグが立てられます。 （GUIDES-48587）

## アセット管理

- 一括アセット処理でコンテンツフラグメントアセットが誤って含まれるので、処理レポートでエラーログやエラーが発生します。 （GUIDES-47085）
- マップパネルで、「マップ」チェックボックスを選択して選択を繰り返し解除すると、子トピックの読み込みが失敗し、展開アイコンが消える。 （GUIDES-43546）

## 公開

**AEM Sites**

複合コンポーネントマッピングを使用してAEM Sites出力を公開する場合：

- 複合コンポーネントマッピングを使用してAEM Sites プリセットで新しいベースラインを使用すると、空白の&#x200B;**トピックリスト**&#x200B;が表示されます。 （GUIDES-46480）
- PDF、ZIP、DOCX、画像ファイルなどのDITA以外のアセットへの相互参照（`xref`）リンクが正しく解決されず、生成されたページのリンクが壊れます。 （GUIDES-44108）

従来のコンポーネントマッピングを使用してAEM Sites出力を公開する場合：

- 生成されたページ名の英語以外のファイル名はハイフンに置き換えられるため、関連するトピックやファイルを特定することが困難です。 （GUIDES-48387）

**ネイティブ PDF**

- ネイティブ PDF出力では、`toc="no"`属性でマークされたトピック参照は引き続き目次に含まれるため、長くて乱雑な目次になります。 （GUIDES-37940、GUIDES-20156）

**コレクションのマップと一括アクティブ化**

Experience Manager Guidesの2020.08.0 リリースで利用可能な[新しいマップコレクション &#x200B;](../user-guide/generate-output-use-new-map-collection-output-generation.md#use-new-map-collection-for-output-generation-beta)機能で、次の問題が修正されました。

- ネットワークエラーが発生したため、100を超えるマップエントリを含むマップコレクションを読み込めません。 （GUIDES-34007）
- マップコレクション UIのフォルダーから複数のマップを一度に選択できません。 （GUIDES-29581）
- マップコレクション UIでマップコレクションを検索またはフィルタリングできません。 （GUIDES-27723）
- 一括公開/アクティベーションダッシュボードを閉じるか、ブラウザーの「戻る」ボタンを使用せずに&#x200B;**ツール**&#x200B;またはホームページに戻ることはできません。 （GUIDES-26797）
- 多数のマップまたは言語を含むマップコレクションを簡単に管理できない。 （GUIDES-21735）
- 生成された出力をマップコレクションまたはバルクアクティベーションダッシュボードインターフェイスから直接表示または公開できない。 （GUIDES-18712）
- マップコレクションとバルクアクティベーションダッシュボードは別々のコレクションのセットを管理するため、1つのコレクションを使用してマップを生成およびアクティベートすることはできません。 （GUIDES-12730）

## レビュー

- レビューUIでは、タグ付けリストにレビュータスクのすべてのユーザーが表示されるため、コメントまたは返信で正しいユーザーを選択することが困難になります。 （GUIDES-33420）
- コメント パネルで&#x200B;**横に** ビューを開くと、作業中のコピーがコメント付きバージョンと一緒に表示されますが、ペインは水平方向にスクロールせず、コメントをクリックしてもカーソルが対応するテキストに移動しません。 （GUIDES-44083）

## データベース

- `DatabaseConfiguratorService`は、設定または有効になっていない場合でも、ログにエラーをスローします。 （GUIDES-43481）

## 既知の問題

Adobeでは、2026.08.0 リリースの次の既知の問題を特定しました。

## オーサリング

- 別の場所に移動されたDITAVAL ファイルを閉じると、`ERROR IN FETCHING VERSION DETAILS` エラーメッセージが表示されます。 （GUIDES-51420）

## エディター2.0


- 競合APIが失敗し、リポジトリーフォルダーのパスがスラッシュで終了すると、アプリケーションエラーが発生します。 （GUIDES-51006）
- アウトライン表示で処理命令エレメントを選択すると、選択したエレメントではなく親タグ全体がハイライト表示されます。 （GUIDES-48318）
- ソースビューの`keyref`内のキーワードを編集すると、ビューが他のビューに切り替えられたときにキーワードが壊れます。 （GUIDES-49998）
- `foreign`および`equation` ブロック内で囲まれたMathML数式は、不要な間隔を設定することになり、数式の内部で入力すると、インデントを調整した後でも問題が発生します。 （GUIDES-46606）
- **タグを表示** オプションが有効で、**属性を表示** オプションがエディター設定で無効になっている場合、`reltable`内の`topicref`にカーソルを配置できません。 （GUIDES-46565）
- 参照を空の`keydef`にドラッグ&amp;ドロップすると、参照を更新する代わりに`topicref`要素が追加されます。 （GUIDES-45068）

## 公開

- Edge Delivery Services出力を生成した後、**出力を表示**&#x200B;を選択すると、`hlx.live` URLが開き、`aem.live` URLの代わりに403 Forbidden エラーが返されます。 （GUIDES-51572）
- テンプレートのツールバーから画像、ハイパーリンク、またはiframeを追加すると、無効なコンポーネントが`common.plt` ページに表示されます。 （GUIDES-51165）
- `copy-to`属性を使用してトピックを参照するマップを公開すると、ソースマップ内の対応するトピックからピアスコープリンクが削除されます。 （GUIDES-50701）
- PDFがスコープが`Peer`に設定された`xref`として参照されている場合、クロスマップから取得するのではなく、AEM サイト（従来のコンポーネントマッピングを使用）で公開されます。 （GUIDES-50213）

**マップコレクション**

- マップコレクションを削除する前にタブ（リポジトリや概要など）を切り替えてマップコレクションページに戻ると、マップコレクションの削除が失敗することがあります。 （GUIDES-50997）
- 前の生成が進行中の間に同じプリセットを生成すると、前の生成が進行中であることを示すメッセージが表示されなくなります。 （GUIDES-50523）
- マップを生成した後、最後の生成タイムスタンプはマップコレクション UIで表示または更新されず、以前に削除したプリセットを再追加すると、その生成履歴が再び失われます。 （GUIDES-50511）
- **生成履歴**&#x200B;からの公開では、選択した生成ではなく、常に最新のプリセット出力が公開されます。 （GUIDES-50508）
- 新しく作成されたマップコレクションの公開ステータスが自動的に更新されない。 （GUIDES-50367）

## 翻訳

- 「**構造のみを作成**」オプションを使用して翻訳を開始すると、エラーが返されます。 （GUIDES-51261）

## レビュー

- 非表示のコンディショナルコンテンツを含むテキストのキーボードショートカットを使用して取り消しを実行すると、非表示のコンテンツも取り消されます。 （GUIDES-49837）
