# MCP – 管理された技術コンテンツへのアクセスの拡大

Model Context Protocol （MCP）により、AIを活用したエクスペリエンスが、既存のAEM Guidesへのアクセス制御と権限を尊重しながら、自然言語のリクエストを通じてAEMと安全にやり取りできるようになった方法をご確認ください。 このセッションでは、MCP アーキテクチャ、設定、認証、およびセキュリティ モデルについて説明し、現在サポートされている機能を示し、実用的なユースケース、現在の境界、および主要な考慮事項について説明します。 また、AEM as a Cloud Serviceおよびオンプレミス/AMS環境のデプロイメントに関する考慮事項についても説明し、MCP対応クライアントがAEM Guidesとどのように連携できるかを示し、MCPがAdobeの広範なAI機能と連携する箇所について説明します。


## セッションの概要

このセッションでは、AEM Guides MCPの設定、設定、使用方法について説明します
