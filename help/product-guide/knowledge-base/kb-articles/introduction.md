# Experience Manager Guides ナレッジベース

ナレッジベースには、コア製品ドキュメント以外の一般的な設定、カスタマイズ、ユースケースをカバーする、Experience Manager Guides向けの実用的なシナリオ駆動型の記事が含まれています。

| カテゴリ | 説明 |
|---|---|
| オーサリング | エディターのカスタマイズ、メタデータ管理、コンテンツ検証など、エディターでコンテンツを作成および再利用するためのヒントとテクニック。 |
| Guides拡張フレームワーク | 拡張機能フレームワークの基本から、カスタムコンポーネント、ウィジェット、レビューアプリのカスタマイズの構築に至るまで、Experience Manager Guides UIをカスタマイズする方法を説明します。 |
| 外部データ Source | Experience Manager Guidesを使用した外部データソースコネクタの統合と設定に関するガイダンス。 |
| 公開 | ネイティブPDF、DITA-OT、AEM Sites テンプレート、マイクロサービスベースの公開設定など、出力生成のベストプラクティス。 |
| ワークフロー | 出力生成後のワークフローを設定および使用して、出力生成後のステップを自動化します。 |
| 翻訳 | 翻訳のパフォーマンスを改善し、翻訳に含めるコンテンツや翻訳から除外するコンテンツを管理する方法に関する説明です。 |
| ユースケース | 公開出力での条件付きコンテンツ、キーの操作、コンテクスト型コンテンツ変数などの実際のシナリオについて説明します。 |
