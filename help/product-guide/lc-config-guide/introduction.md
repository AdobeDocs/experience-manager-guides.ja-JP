# このガイドについて

このガイドでは、Experience Manager Guidesの学習およびトレーニングコンテンツ用に設定する必要があるコア設定について説明します。 これらの設定により、管理者は適切なテンプレートにアクセスし、エディター制御を設定し、サポートされる出力形式で公開できるコースコンテンツを作成するために必要な公開オプションを設定できます。
