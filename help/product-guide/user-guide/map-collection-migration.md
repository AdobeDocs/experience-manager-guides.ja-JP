# 古いマップコレクションを新しいマップコレクションに移行

既に古い形式でマップコレクションを設定している場合、新しいエクスペリエンスに移動する際にゼロからマップコレクションを再構築する必要はありません。 手動で再作成することも、組み込みの移行ツールを使用して、すべてを1 ステップで移動することもできます。

移行ツールは、**バルクプロセッサー**&#x200B;内に新しいプロセスタイプとして追加され、既存の古いマップコレクションを読み取り、一致する新しいマップコレクションを自動的に作成します。 この記事では、移行の実行方法について説明し、移行を使用する前に把握しておくべき重要な動作をいくつか紹介します。

>[!NOTE]
>
> 一括アクティブ化機能は、新しいマップ収集エクスペリエンスに移行されません。 必要に応じて、新しいマップコレクションエクスペリエンスで一括アクティベーションに使用するマップコレクションを再作成します。

## 新しいマップ コレクションへの移行

古いマップコレクションを新しいマップコレクションに移行するには、次の手順を実行します。

1. Adobe Experience Manager ロゴを選択し、**ツール**&#x200B;を選択します。
1. **ツール** パネルで、**ガイド**&#x200B;を選択します。
1. **Bulk Processor** タイルを選択します。

   ![&#x200B; バルクプロセッサタイルをハイライト表示](images/flow-asset-processor.png)

1. Guides Bulk Processor ウィンドウが開き、次の詳細が表示されます。

   - **機能タイプ**：実行中のプロセスの機能を表示します。

   - **実行ID**：実行する移行タスクごとに一意のIDです。

   - **作成者**: タスクの作成者を表示します。

   - **開始時間**：移行が開始された日時を表示します。

   - **終了時間**：移行が終了した日時を表示します。

   - **ステータス**：移行のステータスを「進行中」、「完了」、「失敗」と表示します。

   ![Guides Bulk Processor ウィンドウ &#x200B;](images/guides-asset-processor-migration.png)

1. ウィンドウの右上隅にある「**新しいプロセス**」タブを選択して、新しい移行タスクを開始します。

   **新しいプロセス** ダイアログが開きます。

   ![移行用の新しいプロセスダイアログ &#x200B;](images/new-process-migration.png) {width="350"}

1. 「**機能タイプ**」ドロップダウンから「**マップコレクション**」を選択します。

   ![移行タスクのマップ コレクション機能](images/new-process.png) {width="350"}

1. 「**作成**」を選択します。

これにより、既存のすべての古いマップコレクションを新しいマップコレクションに移行する単一のジョブが実行されます。 追加の設定は必要ありません。

>[!NOTE]
>
> 移行タスクが失敗した場合は、実行IDの上にカーソルを合わせると、**ログを表示** オプションを確認できます。

## 重要な検討事項

- **移行の再実行：**&#x200B;移行プロセスが再度実行された場合、ソース （古い）マップコレクションの変更はチェックされません。 新しいマップコレクションを無条件で再移行または上書きします。
- **タイムスタンプと一意性：**&#x200B;移行された各マップコレクションには、最初に移行された時点のタイムスタンプが格納されます。 このタイムスタンプは、移行されたレコードの一意性を維持するために使用されます。 このため、移行されたマップコレクションは、後で元の（ソース）マップコレクションに加えられた更新を反映せず、移行時の状態のみがキャプチャされます。
