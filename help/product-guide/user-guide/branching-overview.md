# 概要

>[!NOTE]
>
> 分岐と結合機能は、Experience Manager Guides as a Cloud Serviceの2026.11.0 リリースで導入され、デフォルトでは無効になっています。 お客様の環境で機能を有効にするには、カスタマーサクセス部門にお問い合わせください。

Adobe Experience Manager Guidesで分岐すると、DITA マップ用の&#x200B;**main** ブランチから複数のブランチを作成および管理して、様々なドキュメントリリースを並行して作業できます。 各ブランチでは、作成者は、他のブランチの対応するコンテンツに影響を与えることなく、コンテンツの変更を個別に管理できます。

分岐を使用すると、複数のチームが、同じDITA マップに関連する異なるリリース、機能、または修正を同時に作業できます。 更新の準備ができたら、ブランチからデフォルトブランチ （`main`）に変更を結合できます。

## 分岐の仕組み

ブランチは、**main**&#x200B;またはDITA マップの既存のブランチから作成できます。 ブランチを作成したら、ブランチに切り替えて、マップとそのコンテンツの編集を開始できます。 選択したブランチからコンテンツを公開したり、準備ができたら変更を`main`に結合したりすることもできます。

例えば、製品のインストール手順を含む`install-the-lift.ditamap`という名前のDITA マップを考えてみましょう。 ドキュメントチームは、`main`からこのマップの2つのブランチを作成できます。

- **リリース 1:** チーム Aは、既存のインストール手順を維持し、修正を解決します。
- **リリース 2:** チーム Bが、新機能のインストール手順を作成します。

両方のチームは、お互いの変更に影響を与えることなく、それぞれのマップブランチで独立して作業できます。

>[!NOTE]
>
>DITA マップに基づいてブランチが作成されます。 選択したブランチ内のマップで参照されていないトピックを追加および編集することもできます。 詳細については、[現在のマップ以外のトピックを開いたり編集したりします](./create-manage-branch.md#open-or-edit-topics-outside-the-current-map-context)。

DITA マップのブランチを作成する場合、Experience Manager Guidesはマップの参照トピックを新しいブランチに自動的にコピーしません。 変更されていないトピックは、ソースブランチまたはデフォルトブランチ（main）から読み取られます。 トピックは、そのブランチで編集して保存する場合にのみ、新しいブランチにコピーされます。

例えば、DITA マップは100件のトピックを参照し、リポジトリにはマップで参照されない50件の追加トピックが含まれます。 新しいブランチ（release-1.0）を作成すると、100件の参照トピックはすべて、編集されていなくても、自動的にrelease-1.0の一部になります。 参照されていない50個のトピックは、自動的に新しいブランチの一部にはなりません。 そのうち10個を編集した場合、その10個のみがリリース 1.0の一部になります。 残りの40個の未変更のトピックは、デフォルトのブランチ（main）から引き続き使用されます。

>[!NOTE]
>
> トピックのバージョン管理は、分岐で引き続き機能します。 DITA マップの選択したブランチ内でトピックのバージョンを作成および管理できます。 各ブランチは、他のブランチとは独立して、独自のバージョン履歴を保持します。

## 主な特長

Experience Manager Guidesのブランチを操作すると、次のメリットが得られます。

- **個別編集：**&#x200B;他の分岐の対応するコンテンツに影響を与えずに、選択したマップブランチ内で変更を加えます。
- **並列オーサリング：**&#x200B;複数のチームが、それぞれのマップブランチ内の異なるリリース、機能、または修正で同時に作業できるようにします。
- **独立した公開：**&#x200B;他のブランチでの変更が完了するのを待たずに、個々のマップブランチからドキュメントを公開します。
- **制御された結合：** マップブランチからの変更をデフォルトブランチ （`main`）に結合し、競合を確認および解決する機能を備えています。

## 分岐とベースライン

>[!NOTE]
>
> ベースラインと分岐は相互に排他的な機能です。 分岐が有効になっている場合、ベースライン機能は使用できなくなります。 ただし、既存のベースラインはそのまま残り、削除されません。 分岐を後で無効にすると、既存のベースラインが再度使用できるようになります。

**ベースライン**&#x200B;は、DITA マップのトピックバージョンの特定の組み合わせを識別し、選択したバージョンを使用して出力を生成できるようにします。

**ブランチ**&#x200B;は、DITA マップとそのコンテンツに対して個別の編集環境を提供し、作成者が同じマップの他のブランチに影響を与えずに変更を行えるようにします。

| ベースライン | 分岐 |
|---|---|
| DITA マップでトピックの特定のバージョンを選択します。 | DITA マップの分岐を個別に作成して、変更を個別に管理します。 |
| トピックバージョンの特定の組み合わせを公開するために使用されます。 | 様々なリリースを並行して開発および公開するために使用されます。 |
| 独立した編集コンテキストを提供しないでください。 | 独立した編集と結合をサポートします。 |
